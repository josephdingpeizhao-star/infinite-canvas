## NC-01 建批交互防呆

- 角色角标：把图片连到工作流机器后应立即显示“产品原图”（多张带序号），连到已登记信息卡后应显示“风格参考”；同图连到两处应显示冲突，断线后对应角标立即消失，既有 QC 角标仍同时正常显示。
- 接反拦截：同一张产品原图再连到信息卡补登时，应在发出请求前显示“这张图已经是本批的产品原图，不能再登记为风格参考。若是接反了：产品原图连工作流机器，风格参考图连信息卡。”，工作台后端也必须以同一全文拒绝且不产生文件或凭证。
- 正常链路：两张不同产品原图连工作流机器、一张不同风格图连信息卡时，文件名清单与按钮数量应准确，正常建批和补登不受阻，也不增加确认弹窗。
