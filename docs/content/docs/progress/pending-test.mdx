# 待测试

## ST-05 套装建批角色分配

- 状态：连线全集、卡面合影勾选、单件自动派生和双端失败关闭校验已完成，仍需真人在工作台验证；自动检查只使用内存节点、临时文件和静态渲染，零端口、零网络、零模型调用、零费用。
- 唯一入口：把套装全部白底图（合影和各单件）从底部“上传素材”拖入画布，并全部连接到同一台工作流机器；信息卡不再显示套装二次上传按钮，也不应额外创建图片节点。
- 角色分配：选择“套装”后，卡片应列出全部已连线图片的文件名；勾选 1–3 张为“合影”，其余自动计为 2–8 张各单件白底图，计数越界时显示红字并禁止登记。
- 断线与重复：勾选为合影的图片断线后应提示重新勾选；同内容图片即使分别作为合影和单件仍应按原重复图文案拒绝，同名不同内容仍应在后端拒绝。
- 切换与锁定：切换到任一商品类型都应清空旧合影勾选；登记排队后角色列表只读，登记完成回执继续显示“套装图片 合影 X + 单件 Y”。
- 单品与制作边界：单品默认、原图连线、品类事实、登记命令、后续制作、费用确认与三道查重保持不变；登记动作本身不启动制作、不调用模型、不产生费用。

- 套装归零：单品状态下先填写任意合法手持数量，再选择“套装”；主图手持和详情图手持应立即显示为 0、输入框置灰且无法选择或改动，卡片汇总也应显示“手持：主 0 + 详情 0”。
- 状态保持：套装状态下切换产品品类或刷新包含历史非零手持值的旧画布，两项手持仍应保持为 0，不得恢复旧值或品类默认值。

## ST-03b 套装建批尺寸选填

- 尺寸语义：后续套装配置只应使用《套装产品身份档案》与各单件《产品身份档案》的真实尺寸字段，不得把信息卡空尺寸拼成文字或作为精确尺寸依据。

## BC-01 多选节点一次性连线到同一目标

- 混选反馈：选中集合含目标自身、折叠批次隐藏子节点、Group、Config 或已有连线时，可连接项仍应成功；存在重复或拒绝项时应按实际数量显示一条汇总提示，不得整批失败或静默跳过。
- 单条兼容：未形成有效多选时，普通拖线、目标自连、重复连线和“配置节点之间不能连接”的既有行为与文案应保持不变。
- 唯一编号：批量建立后，任选一条连线进行选中或删除，只应影响该条连线，不得整批高亮或整批删除。

## ER-02f 图片服务失败归因

## RB-01 白底图缺失分级处置

- 个别缺失：在尚未出图、白底图目录仍可用且至少剩 1 张的失败机器上，应显示可读原因与“剔除缺失图并重新分配”；点击后先完成零费用重排，再重新报价并由用户亲手确认费用，确认前不得写生产命令。

- 旧行为：其他失败卡主按钮仍逐字显示“重新开始”，点击后完全不发送剔除 POST，继续走原有报价与人工费用确认；排队中和制作中的互斥行为不变。
- 失败关闭：机器元数据或重新分配响应任一字段不可信时，不显示剔除按钮、不推进报价；可信的本机拒绝原因应原样显示，且不得自动重试。

## RS-01 终态后免刷新重新提交

## EX-01 工作流节点图片下载与返修入口休眠

- 状态：功能与自动检查已完成，尚未真人验证；自动检查仅使用内存节点与本地替身，零网络、零真实模型调用、零费用，未创建、读取或修改任何真实批次及其工作区。
- 入口终态：打开一台已完成的真实工作流机器，应显示“下载选中的图片”和“下载所有图片”；“上桌返修图”默认隐藏，既有返修投影接线与未来单点开关接回能力保留。无信息卡的演示机器保持原样。
- 选中下载：只选本批一张或多张正式图、返修图时，按钮应可用且下载数量正确；未选图片，或只选其他批次、无关图片时应置灰，不得混入下载。
- 全部下载：应只下载本批已持久化且证据完整的正式图、返修图；本批没有合格成图时应置灰。节点类型、浏览器存储凭证、批次号、图位、来源或 SHA-256 任一不合格的图片都应排除。
- 方式弹窗：两个下载入口都应显示“选择下载方式”、批次号和本次张数；取消应零下载；可分别选择“打包为 ZIP 下载”或“逐张下载”，并能看到浏览器可能询问是否允许下载多个文件的说明。
- 文件合同：ZIP 名应为“批次号.zip”；正式图名应为“图位号.png”，返修图名应为“图位号_返修.png”，同图位不得撞名；顺序按本批图位排列，正式图在返修图前，逐张模式使用相同名称。
- 缺失兜底：人为让一张浏览器持久化图片失效后，应下载其余可用图片，并提示“已下载 M/N 张，缺失：图位号…”；全部可用时不应出现缺失提示。
- 布局边界：默认两个下载按钮在浅色、深色主题下都应完整可读；未来单独或同时接回“上桌返修图”“已收货框”时，按钮应自然回排，不重叠、不截断。

## HF-01 失败原因与重新开始自愈

- 状态：主仓与前端自动检查已完成，尚未真人验证；自动检查只使用临时目录、内存画布与假报价，没有读取或修改真实批次、真实工作区或冻结账本。
