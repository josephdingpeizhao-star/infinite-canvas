Infinite Canvas Windows 便携版首次部署检查单

一、首次部署（三步）
1. 右键 ZIP 压缩包，选择“全部解压”，再打开解压后的完整文件夹。不要直接在压缩包中运行，也不要只复制 Infinite Canvas.exe。
2. 压缩包已内置出图凭据，完整解压后即可真实出图，无需另放文件；如需更换或停用，替换或删除 Infinite Canvas.exe 同目录的 render-credentials.json 后重启程序。
3. 双击“Infinite Canvas.exe”。首次运行若 Windows SmartScreen 显示“已保护你的电脑”，请先确认压缩包来源和校验值，再点“更多信息”→“仍要运行”。

二、首次 Codex 授权
1. 打开画布右上角 Agent 面板，进入设置页的“Codex 账号”。
2. 确认本机 Agent 已连接，再点“去官方登录”。
3. 在系统浏览器中完成官方账号授权。
4. 回到 Agent 面板，等待状态自动变为“已登录”；若浏览器没有自动打开，可到面板“日志”页查看官方授权地址。

为保护账号安全，便携包不会携带其他电脑的 Codex 登录状态，也不要复制 Codex 的 auth.json、Cookie 或浏览器用户数据。

三、识图与提示词生成模型
1. 默认使用 Codex 登录账号（gpt-5.5，medium），无需设置。
2. 如需改用其它模型（如千问）：在「配置 → 渠道」填写该渠道的 Base URL 与 API Key 并拉取模型，再到「配置 → 模型」底部「识图与提示词生成模型」选择；状态行显示「已同步到本机工作台」即生效。该选择与渠道 Key 保存在本机用户目录 .infinite-canvas 下，不进入“文档\无限画布工作流”，也不随批次数据迁移。
3. 每个批次在建批时记录所用模型；中途切换后继续旧批次会被拦下并提示切回。

四、数据位置与程序升级
1. 用户数据固定保存在当前 Windows 用户的“文档\无限画布工作流”中，不在解压后的程序目录内。
2. 首次启动会自动创建 workflow-runtime\manifests、workflow-runtime\reports 和“杯类”三个数据目录；请勿把它们手工放回程序目录。
3. 更新时可以完整删除旧程序目录，再解压新版 ZIP 并启动；“文档\无限画布工作流”中的批次工作区、账本和报告不受影响。
4. 把 ZIP 交给同事时，他首次启动会在自己的“文档\无限画布工作流”中创建独立数据目录。

五、部署自检清单
[ ] 双击 Infinite Canvas.exe 后程序能够正常打开，并能进入“我的画布”。
[ ] 新建信息卡时能读到杯类、盘子、碗三个品类。
[ ] 信息卡中的“单品/套装”可以正常选择。
[ ] 配置 → 模型 底部能看到“识图与提示词生成模型”，且状态行为“已同步到本机工作台”
[ ] 连接并登记 2 张原图后，信息卡能显示登记回执；登记本身不启动制作、不调用模型、不产生费用。
[ ] “文档\无限画布工作流”下已创建 workflow-runtime\manifests、workflow-runtime\reports 和“杯类”，程序目录中没有批次账本、报告或批次工作区。
[ ] 完全退出桌面程序后，本机 3000、17371、17372、17373 四个服务端口不再监听。
