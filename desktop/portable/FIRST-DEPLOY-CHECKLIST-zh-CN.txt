Infinite Canvas Windows 便携版首次部署检查单

一、首次部署（三步）
1. 右键 ZIP 压缩包，选择“全部解压”，再打开解压后的完整文件夹。不要直接在压缩包中运行，也不要只复制 Infinite Canvas.exe。
2. 如需真实出图，可把现有 render-credentials.json 放到 Infinite Canvas.exe 同一目录；不放或文件无效时，真实渲染保持锁定，画布、批次登记和 Codex 等其他功能仍可使用。
3. 双击“Infinite Canvas.exe”。首次运行若 Windows SmartScreen 显示“已保护你的电脑”，请先确认压缩包来源和校验值，再点“更多信息”→“仍要运行”。

二、首次 Codex 授权
1. 打开画布右上角 Agent 面板，进入设置页的“Codex 账号”。
2. 确认本机 Agent 已连接，再点“去官方登录”。
3. 在系统浏览器中完成官方账号授权。
4. 回到 Agent 面板，等待状态自动变为“已登录”；若浏览器没有自动打开，可到面板“日志”页查看官方授权地址。

为保护账号安全，便携包不会携带其他电脑的 Codex 登录状态，也不要复制任何账号凭据文件、Cookie 或浏览器用户数据。

三、旧批次迁移
1. 把旧电脑“杯类\<批次目录>”完整复制到本程序目录的“杯类\”中，不要改变批次目录名。
2. 把旧电脑 workflow-runtime\manifests\ 中同一批次号的 .batch_manifest.json 与 .events.jsonl 一并复制到新电脑相同目录。
3. 在途批次必须同时带上上述两份记录；已完结批次也建议一并带上，便于后续核对和继续使用。

四、部署自检清单
[ ] 双击 Infinite Canvas.exe 后程序能够正常打开，并能进入“我的画布”。
[ ] 新建信息卡时能读到杯类、盘子、碗三个品类。
[ ] 信息卡中的“单品/套装”可以正常选择。
[ ] 连接并登记 2 张原图后，信息卡能显示登记回执；登记本身不启动制作、不调用模型、不产生费用。
[ ] 完全退出桌面程序后，本机 3000、17371、17372、17373 四个服务端口不再监听。
